========================================================
적·스테이지 추가 방법 (EnemyBase + EnemyData + StageData)
========================================================

구조
  Prefabs/Enemies/EnemyBase.prefab     ← 공통 구조 1개
  Resources/EnemyData/*.asset          ← 스탯·스프라이트·EnemyType·EnemyRole·EnemyTier
  Resources/Stages/StageXX.asset       ← stageId + waves[] (EnemyType + EnemyTier + spawnWeight)

  ※ Base는 Resources에 두지 않음. EnemySpawner 인스펙터에 직접 할당.
  ※ 웨이브에 프리팹/EnemyData SO를 직접 넣지 않음. Type+Tier 드롭다운만.

■ 최초 1회 (에디터 메뉴)
  RPD/Enemies/1. Create EnemyBase Prefab
  RPD/Enemies/2. Sync Sprites Prefab → EnemyData
  RPD/Enemies/3. Assign EnemyBase To Scene Spawner

■ 새 적 추가
  1) 새 역할이면 EnemyType enum 끝에 값 추가 (순서 바꾸지 말 것)
     같은 역할의 상위 강도만이면 Type 추가 없이 enemyTier만 올린 SO 생성
  2) Create → RPD → Enemy Data → Resources/EnemyData 에 저장
     파일명 예: E01_Swarm_T2, E07_Carrier_T1
  3) enemyType / enemyRole / enemyTier / gold / hp / speed / sprite 설정
     - Tier↑: HP·속도·골드 위주 (역할별 비율 다름)
     - Shielded: shieldHp > 0
     - Splitter: splitCount + splitChildType (보통 Swarm T1)
  4) Stage 웨이브 enemies에 enemyType + enemyTier + spawnWeight

■ 역할 (EnemyRole) — Type/Tier와 별개
  Runner   빠름. 상위는 같은 Type + Tier2/3
  Tank     높은 HP·낮은 속도
  Swarm    약한 다수. Splitter 잔해는 Swarm T1
  Shielded 실드 HP가 본체보다 먼저 깎임
  Splitter Kill 시 잔해 스폰

■ 티어 (EnemyTier) 1~3
  같은 EnemyType의 강도 단계. 웨이브에서 Type과 함께 지정.
  레거시 RunnerElite 슬롯은 Runner T2로 자동 해석.

■ 새 스테이지 추가 (아웃게임용)
  1) Create → RPD → Stage Data → Resources/Stages
  2) stageId (고유), displayName, waves[]
  3) WaveSystem.stageId 또는 ConfigureStage(id) 로 선택

■ spawnWeight (출현 비중)
  - 합이 1일 필요 없음. 상대 가중치.
  - 예: 2와 1 → 약 66% / 33%
  - 0이면 그 슬롯은 스폰 안 함
  - 타워 catalog.spawnWeight 와 같은 방식

■ 스폰 흐름
  StageCatalog(stageId) → Wave → EnemyType
  → EnemyCatalog → EnemyData
  → EnemyBase 풀 스폰 → BindDefinition

■ 하지 않기
  - 적 종류마다 프리팹 복제 (보스 등 구조 다를 때만 Base 추가)
  - Stage에 프리팹/EnemyData 오브젝트 참조
  - Base를 Resources에 넣기
