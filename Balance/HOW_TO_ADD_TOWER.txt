========================================================
새 타워 추가 방법 (Base + Data)
========================================================

구조
  Prefabs/Towers/Bases/*Base.prefab  ← 무기 계열 구조 (소수)
  Resources/TowerData/*.asset        ← 등급·스탯·스프라이트 (다수)
  Resources/TowerBaseLibrary         ← weaponType → Base 매핑

■ 기존 무기 계열에 등급/스킨만 추가 (가장 흔함)
  1) Resources/TowerData/ 에 TowerData SO
     - towerId, grade, weaponType(기존), sprite, spriteColor, 스탯
     - 프리팹 슬롯 없음 (BaseLibrary가 weaponType으로 연결)
     - 무기 타입별 전용 필드가 인스펙터에 뜸
       MultiWayShooting : 발사 수 · 확산각
       GroundBombLine   : 폭탄 수 · 라인 길이 · 설치 간격
       Laser/MultiLaser : 레이저 굵기 (0이면 프리팹 값)
  2) (선택) TowerBalance.csv 한 줄
  → 같은 CannonBase 등을 쓰며 스프라이트·색·수치만 달라짐

■ 새 무기 계열 (구조가 다를 때)
  1) Prefabs/Towers/Bases/ 에 새 *Base 프리팹
     (가능하면 TowerBase의 Prefab Variant)
  2) TowerBaseLibrary 에 weaponType ↔ Base 등록
  3) WeaponType enum + ITowerBehavior + Factory (새 공격일 때)
  4) TowerData SO 추가

■ 밸런스 CSV (메뉴)
  RPD/Towers/Export TowerData → Balance CSV
    SO 수치 → Balance/TowerBalance.csv + Resources/TowerBalance.csv
  RPD/Towers/Import Balance CSV → TowerData
    CSV → SO에 덮어쓰기 (towerId 매칭). Balance 파일 우선

■ 머지
  상점 = grade 1 풀 / 같은 type+grade 3개 → grade+1

■ 발사체
  TowerData.projectileType (Auto=무기 기본). Library: Resources/ProjectileBaseLibrary
  상세: Balance/HOW_TO_ADD_PROJECTILE.txt
  메뉴: RPD/Projectiles/1. Create Or Refresh Base Library

■ 지정 타워 테스트 (Editor / Development Build 전용)
  1) 플레이 중 F8 → Tower Debug Spawner
  2) 원하는 TowerData 선택
  3) 패널 밖 좌클릭으로 WallMap 셀에 즉시 배치
  - 골드 차감 없음, 실제 TowerData·BaseLibrary·Addressables 로딩 경로는 그대로 사용

■ 실수
  - LevelMark 자식을 베이스로 쓰기
  - Library에 새 타입 등록 안 함
  - TowerData만 Resources 밖 폴더에 두기
